## 📌 Project Overview

This project was designed and developed by **Aditya Wadnere** as a college web development assignment. It showcases an interactive fixed navigation bar that dynamically reacts to scroll events, active section tracking, smooth page navigation, responsive mobile drawer controls, client-side form validation, and interactive image gallery modals—all implemented strictly using vanilla web standards without third-party frameworks.

---

## ✨ Key Features

- **Fixed Scrolled Navigation:**
  - Stays pinned at the top across all viewports.
  - Dynamically transitions background colors from transparent glass to high-contrast dark navy upon scrolling.
  - Interactive hover state with text glow and animated gradient underline.
  - Active Section Indicator (ScrollSpy) highlighting the section currently visible in the viewport.
- **Mobile Responsive Drawer:**
  - Animated 3-bar hamburger icon morphing into an "X".
  - Slide-down mobile drawer that automatically closes when a navigation anchor is clicked.
- **Interactive Sections:**
  - **Home:** Modern hero section with call-to-action buttons, badges, and a live code preview widget displaying real-time scroll position.
  - **About:** Details about the author (Aditya Wadnere), project objectives, feature cards, and key metrics.
  - **Services:** 4 service cards featuring embedded SVG icons and hover lift effects.
  - **Projects:** Sample portfolio cards with tags, descriptions, and interactive preview triggers.
  - **Gallery:** Responsive image grid with category filtering (Interfaces, Code, Workspaces) and an interactive Lightbox Zoom modal.
  - **Contact:** Clean contact form with client-side JavaScript validation (regex email check, character counter, required fields) and instant submission feedback.
- **Scroll-to-Top:** Floating circular button that smoothly scrolls back to the top of the page.

## 🚀 How to Run Locally

No build tools, bundlers, or servers required:

1. Clone or download this repository:
   ```bash
   git clone https://github.com/<YOUR-USERNAME>/interactive-navigation-menu.git
   ```
2. Navigate into the project folder:
   ```bash
   cd interactive-navigation-menu
   ```
3. Open `index.html` directly in your favorite browser (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari).

## 🌐 Deploy to GitHub Pages (Live Demo)

To make your website live on the web for free:

1. Go to your repository on **GitHub**.
2. Click on **Settings** > **Pages** (in the left sidebar).
3. Under **Branch**, select `main` and root folder `/ (root)`, then click **Save**.
4. Within 1–2 minutes, your website will be live at:
   ```
   https://<your-username>.github.io/<repo-name>/
   ```
