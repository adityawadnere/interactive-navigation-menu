About The Project & Creator

Bridging Clean Code & Interactive Design

A purposeful web development assignment demonstrating responsive layouts, interactive event handling, and modern UI engineering.

AW

Aditya Wadnere

Web Development Student & Designer

Hello! I am Aditya Wadnere. This website was developed as a flagship college web development project to demonstrate proficiency in core web standards: HTML5, CSS3, and Vanilla JavaScript without relying on bulky external frameworks.

The primary focus of this project is mastering an interactive fixed navigation menu that tracks real-time scroll position, seamlessly shifts color palettes upon scrolling, animates underlines and hover states, and offers an intuitive mobile navigation drawer.

Course: Web Development Assignment
Architecture: Single-Page Multi-Section (SPA)
Files Allowed: Exact 3 Files (index, style, script)

Fixed Scroll Physics

Navbar transitions from transparent to high-contrast navy glassmorphism with subtle drop shadows upon user scroll.

Active Section Spy

IntersectionObserver dynamically tracks viewport boundaries and highlights the corresponding menu item in real time.

Mobile Hamburger

Responsive toggling drawer with animated bars, smooth mobile transition, and auto-close when links are clicked.

Zero Dependency

Built purely with native web APIs for peak loading speed, accessible DOM structure, and clean maintainable code.
